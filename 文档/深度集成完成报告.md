## 🔄 新的完整流水线

现在 Orchestrator 的状态机原生包含以下环节：

```
1. 启动 → 自动分配唯一 Trace ID
2. 澄清阶段 → 生成结构化需求
3. 方案阶段 → 生成文件修改方案
4. 【新增】自动风险评估 → 输出 0-100 分 + 低/中/高风险等级
5. 【新增】自动生成大白话摘要 → PM 30秒看懂变更
6. 暂停 → plan-ready 等待 PM 确认
7. 编码阶段 → AI 生成完整代码
8. 【新增】增强 Diff 安全检查 → 检测无关变更
9. 原有 Diff 检查 → 基础校验
10. 测试阶段 → Lint + Build + 单测
11. 暂停 → diff-ready 等待 PM 确认
12. 提交 → 生成 PR
```

## 📊 新增数据库字段（自动迁移）

数据库启动时自动执行 ALTER TABLE，零手动操作：
- `confidence_score INTEGER` - 需求置信度分数
- `risk_level TEXT` - 风险等级 low/medium/high
- `natural_language_summary TEXT` - JSON 序列化的大白话摘要
- `trace_id TEXT` - 全链路追踪 ID
- `auto_approve INTEGER` - 是否支持一键自动执行

## 🚀 如何使用新功能

### 启动服务
```bash
# 启动后端
npm run dev:backend

# 启动前端
npm run dev:frontend
```

所有新功能默认自动启用，无需任何配置开关。

### 低风险需求自动执行
当风险评估得分 ≥ 80 分时，系统自动标记为低风险，PM 可以直接点击「一键自动执行」跳过人工审核，直接进入编码阶段。

## ✨ 新事件流

SSE 现在会推送以下新增事件：
1. `trace-id: xxx` - 显示当前需求的全链路追踪 ID
2. `risk-assessment` - 正在执行风险评估
3. `risk-assessed` - 风险评估完成，返回完整评估结果
4. `plan-ready` 事件新增字段：
   - `riskAssessment` - 风险评估详情
   - `naturalSummary` - 大白话变更摘要
5. `enhanced-diff-safety-check` - 正在执行增强 Diff 安全检查
6. `diff-ready` 事件新增字段：
   - `diffCheck` - 安全检查结果详情
